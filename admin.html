Ekspor ke GitHub & Backup Data

Simpan perubahan permanen ke repositori GitHub Pages atau cadangkan ke file JSON.

Cara Update Data ke GitHub Pages (Sangat Mudah)

  1. Klik tombol "Download data.js" di bawah ini.
  2. Pindahkan/timpa berkas yang terunduh tersebut ke dalam folder proyek Anda: career/js/data.js
  3. Buka terminal di folder career dan jalankan:
    git add .
    git commit -m "update: perbarui data portofolio dari admin"
    git push
  4. Selesai! Website live di GitHub Pages akan langsung terupdate otomatis.
